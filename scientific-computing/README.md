# 科学计算（Scientific Computing）

本目录收录以数值算法、标准实现与科学数据集为核心的库与工具。与框架类项目不同，这类项目的价值主要在"算得对、可复现、能对照文献"。

|------|------|------|------|
| [Colour 项目 Wiki](colour-wiki/README.md) | Markdown（文档 + 15 张 Mermaid 图） | 面向**不打算读源码的人**的 Colour（colour-science）中文项目 Wiki（13 页 / 零外部资源，基线 `v0.4.7` @ `a3bfe3496`）：一条自顶向下的阅读线——色彩科学库的定位与边界（算法与数据集库，不是色彩管理流程），五个基础概念（颜色表示、连续信号、域-范围尺度、自动转换图、数据集注册表），25 个子包的分层与一次转换的完整链路，自动转换图与 RGB 色彩空间对象、色适应与色域体积，光谱分布/多光谱数据与两条积分路径（ASTM E308 加权表法、直接积分法），12 个颜色外观模型与 CAM16 的计算过程，色差公式家族与 CIEDE2000、STRESS 一致性评估，相机/显示特性化与 ACES IDT、图像/LUT/OCIO/光谱文件读写，色温与 Duv、CRI/CQS/TM-30/CIE 2017 CFI/SSI，色域体积/光谱恢复/光学现象/色觉缺陷/对应色等专门模块，以及工程实践（仅依赖 NumPy、缓存与全局尺度状态、测试与发布）；并单列选型硬事实（`v0.4.7` 无 Array API 兼容、无 JAX/PyTorch 后端、无自动微分，部分外观模型只有正向计算） | [GitHub](https://github.com/colour-science/colour) |
