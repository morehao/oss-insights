# 后台系统与管理平台（Admin）

本目录收录后台管理系统（管理面板 / 后台框架 / 工作流引擎 / 后台类业务系统）领域的开源项目解读。

| 项目 | 语言 | 说明 | 协议 | 仓库 |
|------|------|------|------|------|
| [GoAdmin](go-admin/) | Go | 面向 Go 生态的数据管理后台生成框架，声明式 table model + 多 Web 框架适配器 + 开箱即用 RBAC | Apache-2.0 | [GitHub](https://github.com/GoAdminGroup/go-admin) |
| [easy-workflow](easy-workflow/) | Go | 面向中国式审批场景的轻量工作流引擎：JSON 定义流程 + 混合网关 + 会签/自由驳回 + 反射事件 + MySQL 双表归档，可内嵌库或独立 REST 服务 | MIT | [GitHub](https://github.com/Bunny3th/easy-workflow) |
| [zero-admin](zero-admin/) | Go | 基于 go-zero 的电商微服务系统：2 网关 + 8 rpc + consumer/job + goctl 代码生成，覆盖前台商城（订单/支付）+ 后台管理（RBAC）；逻辑分域存储 + ES 搜索 + MQ 异步 | Apache-2.0 | [GitHub](https://github.com/feihua/zero-admin) |
| [PocketBase](pocketbase/) | Go | 开源 BaaS 引擎，单二进制集成 SQLite + 认证 + 文件存储 + 实时订阅 | MIT | [GitHub](https://github.com/pocketbase/pocketbase) |
