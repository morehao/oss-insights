- **dsh-v0.2.3-alpha.2** (2026-11-22) — 这是一个预发布的小版本，只调整了运行环境要求，没有功能层面的改动。

**主要变更**
- 调整 Node.js 版本要求：24.x 系列需使用 24.22.3 及以上，或 26.x 系列需使用 26.13.1 及以上（贡献者 @imccyu）。

**破坏性变更**
- 对仍在使用较旧 Node.js 版本的用户来说，这次调整版本要求可能造成兼容性影响：低于上述版本的 Node.js 环境将不再满足运行条件，升级前需先升级 Node.js。

**升级建议**
- 如果你当前使用的 Node.js 版本已经满足新的最低版本要求，升级基本没有额外成本；如果版本较低，建议先把 Node.js 升级到符合要求的版本，再升级本版本。
  链接: https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.3-alpha.2
- **dsh-v0.2.3-alpha.1** (2026-11-22) — dsh-v0.2.3-alpha.1 是一个以插件生态和会话体验为主的大版本更新，同时包含若干需要迁移适配的破坏性变更。

**主要变更**
- 插件市场支持添加 Git 仓库（含私有仓库）作为插件来源；插件页可直接打开设置，并统一管理连接器账号，MCP 支持 OAuth 授权与凭据自动刷新。
- 新增实验性时间线插件，可查看任务树、阻塞事项和进展报告；新增代码审阅页面与审阅插件扩展机制，支持 GitHub PR 与 GitLab 评审合并。
- 新增会话状态区域、会话已读/未读状态；Web 连接模式新增远程登录（独立链接或设备配对）。
- 新增 Linear、Notion、腾讯文档、飞书、企业微信、腾讯会议、钉钉等可选连接器插件。
- 修复切换模型后首个请求超出上下文导致会话卡住、Python wheel 等单文件运行时恢复旧会话失败、read/glob 处理大文件占用过多内存等问题；Windows 安装拖动卡输入、编辑器启动失败等多项桌面端问题也一并修复。

**破坏性变更**
- Office 技能统一通过 /office 提供，旧格式命令和自定义配置需迁移。
- 系统提示词改为按来源增量更新、压缩后重建；SDK 时区处理调整，自定义集成需按升级指南适配。
- 同步 Cordis 上游至 4.0.0-rc.12，相关 API、YAML 解析和配置校验有调整，插件与自定义配置需迁移。
- 图片缩图逻辑调整，自定义图片配置需适配；依赖 fileAddressFor 返回相对地址的插件需适配。

**升级建议**
- 该版本功能增量明显，插件作者和重度用户值得升级；但涉及 Cordis、Office 技能、系统提示词与时区等多处迁移，升级前应阅读升级指南并预留适配时间。当前为 alpha 版本，建议先在非关键环境验证。
  链接: https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.3-alpha.1

## [morehao/dsh-github-trending](https://github.com/morehao/dsh-github-trending) · v0.9.33 · 2026-11-16 ~ 2026-11-22

- **v0.9.33** (2026-11-20) — v0.9.33 是一次针对模型网关兼容性的小型修复版本。

**主要变更**
- 修复预检与回环代理转发未携带 sessionId 的问题，为相关请求补上会话标识，解决 opencode-go 等按会话路由的模型网关因缺少 x-opencode-session 头而返回 400 MissingSessionID 的情况（#192）。
- 此前该 400 错误会被误判为模型不可用，直接导致运行被拒绝；本次修复后，使用此类网关时可正常通过预检并完成转发。

**破坏性变更**
- 无。本次仅补充请求字段，未改动配置或接口行为。

**升级建议**
- 若使用 opencode-go 或其他依赖会话头路由的模型网关，建议升级；其他用户升级风险低，可按常规节奏跟进。
  链接: https://github.com/morehao/dsh-github-trending/releases/tag/v0.9.33
- **v0.9.32** (2026-11-18) — v0.9.32 是一个以修复为主的小版本，重点是让设置页的「测试认证」在失败时给出更准确的错误分类，而不是统一显示「认证失败」。

**主要变更**
- 设置页「测试认证」在 GitHub 认证探测出错时会按类型分类，包括 TLS 证书、网络、超时、token 无效四类。
- 不同错误类型的提示会指向对应的排查方向，便于用户定位问题（#189）。

**破坏性变更**
- 本次发布未提及破坏性变更。

**升级建议**
- 属于错误提示体验改进，风险低，遇到认证探活排查困难的用户可以升级。
  链接: https://github.com/morehao/dsh-github-trending/releases/tag/v0.9.32
