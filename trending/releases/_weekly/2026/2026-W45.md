# 2026-11-08 发版摘要

## [infiniflow/ragflow](https://github.com/infiniflow/ragflow) · v1.0.0 · 2026-10-19 ~ 2026-10-25

- **v1.0.0** (2026-11-06) — RAGFlow v1.0.0 是一次以功能扩展、解析与模型稳定性修复为主的版本发布。

**主要变更**
- 新增 Wally 模型提供商和 AnySearch 网页搜索提供商，扩展模型与搜索接入。
- 新增 Vastbase G100 作为 Go 侧元数据库支持，并补充文件 API 审计钩子和日志钩子。
- 管理端增加用户搜索、状态筛选、排序和 CLI 分页；聊天消息列表改为虚拟化以提升性能。
- 解析侧支持将 Markdown/HTML 远程图片作为媒体引用处理，并修复 PDF 目录引导线混入正文、PDF 子分块互相覆盖、MinerU JSON 内联压缩包图片字节等问题。
- 模型与工具侧修复 Anthropic 工具参数结构 JSON Schema、模型请求上下文取消、模型目录并发发布竞态，以及 DeepL/QWeather 凭据从节点配置或环境变量读取。
- 其他修复包括 Dropbox 下载失败保留检查点、datasets API 错误响应体结构、PaddleOCR 提交请求错误处理、工具 HTTP 响应体限制 4 MiB、Dify 空元数据条件保持检索不限定范围等。

**破坏性变更**
- 发布说明未明确标注破坏性变更。

**升级建议**
- 本次包含较多功能新增和稳定性修复，涉及解析、模型接入、管理端与工具调用的用户建议升级；升级前仍应结合自身部署的元数据库、模型提供商和解析流程做回归验证。
  链接: https://github.com/infiniflow/ragflow/releases/tag/v1.0.0

- **v0.9.13** (2026-11-06) — v0.9.13 主要新增了可配置的「摘要语言」，同时把核心与契约的配套版本要求一起抬高。

**主要变更**
- 新增「摘要语言」设置：日报与订阅摘要的输出语言不再固定为中文。默认跟随宿主 locale（zh 输出中文、en 输出英文，中英之外一律回落中文），也可在「设置 → 摘要与用量」里显式选择中文或 English。
- 语言解析顺序为「显式设置 > 宿主 locale.preference（归一主标签）> 中文兜底」，每次运行实时读取宿主偏好，并在运行时写入核心 YAML 的 language.outputLanguage。
- 设置页新增语言下拉项；/state 新增 language 信息，包含 hostLanguage、resolvedLanguage、outputLanguageSource。
- 修复「榜单(scope)」tab 内 summarize / schedule 编辑不持久化的问题。

**破坏性变更**
- 核心最低版本提升至 0.12.0，低于该版本会判定为 CORE_INCOMPATIBLE 并给出下载引导；核心 0.12.0 起才支持 language.outputLanguage 与 digest.summary / summaryLang。
- 契约包 @morehao/trendradar-contract 升级到 0.7.0，wire 层为 ipcSchema=4、digestSchema=3、contractVersion=0.7.0；摘要字段由 summaryZh 改为 summary 加 summaryLang，消费旧字段的下游需要同步适配。

**升级建议**
- 升级本版本时需同时把核心升到 0.12.0 及以上，并按契约 0.7.0 调整摘要字段的读取逻辑，否则可能遇到不兼容判定或字段缺失。
- 有英文摘要需求、或受 scope tab 编辑不持久化影响的用户值得升级；纯中文场景且下游尚未适配新契约的，可等核心与消费方一并就绪后再升。
  链接: https://github.com/morehao/dsh-github-trending/releases/tag/v0.9.13
