## 2026-11-09 ~ 2026-11-15

- [dsh-v0.2.2-rc.2](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2) · 11-11

  这是 dsh-v0.2.2 的候选版本，主要改进 Git Worktree 审阅、多层 SubAgent 协作、多项交互体验与稳定性修复；同时包含若干需要迁移适配的破坏性变更。
  
  **主要变更**
  - Git Worktree 支持按分支、提交和文件类型审阅改动，可直接处理 GitHub 评审、同步已审阅进度和更新分支。
  - SubAgent 支持具名与多层协作，AgentTeam 可按会话开启并共用成员与任务面板；SDK 可为新会话默认开启团队协作。
  - 桌面端可在设置中切换正式版与开发版更新渠道，并可通过下载百分比查看更新进度。
  - 聊天体验增强：向上回看自动加载更早消息、可展开查看模型收到的上下文、代码差异按语言高亮并显示增删行颜色、粘贴图片更灵活、请求失败后可直接继续生成。
  - 侧栏文件查找、菜单定位、暗色模式浮层、窄屏布局与长列表滚动等交互均有优化。
  - 插件可动态注册与移除 MCP 服务，并可按语言扩展代码块显示；新增 Gemini 原生接口与账号通知支持。
  
  **问题修复**
  - 修复 PR 更新后审阅差异与提交行号不一致、仅有 SSH 凭据时无法查看私有插件详情、可选插件加载失败导致整个 Web 页面无法启动等问题。
  - 修复会话更新出错后历史加载卡住、消息重复提交、停止任务未中止、桌面端多次启动后无法启动、连续浏览 PDF 逐渐变慢等稳定性问题。
  - 修复 Anthropic Messages 接入下失效签名 thinking、部分网关错误被误报为 API 密钥无效等问题。
  
  **破坏性变更与迁移**
  - 网页搜索默认改用 DeepSeek Search API，旧提供方与自定义配置需按升级指南调整。
  - 归档会话默认清理符合条件的 Git 工作树（保留分支与提交），自定义配置与 Forge 插件需迁移。
  - AgentTeam 改用统一的具名子代理，中断工具默认关闭；自定义插件与 SDK 集成需迁移，共享会话的进程须同步升级。
  - 自定义浮层需适配新的菜单定位接口；Creator 开发指引统一到 dsh-doc，引用旧技能名称或路径的扩展需迁移。
  - 工具失败的错误类型与代码有调整，依赖旧错误分类的插件和 SDK 集成需适配；Session 批量追加事件的包装代码也需适配。
  
  **升级建议**
  - 该版本为候选版且含多项迁移项，建议先在测试环境验证，并按升级指南完成搜索、工作树清理与 AgentTeam 相关配置迁移后再推广。

## 2026-11-02 ~ 2026-11-08

- [dsh-v0.2.2-rc.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.1) · 11-04

本周发布 1 个版本 dsh-v0.2.2-rc.1，它是 0.2.2 系列的首个候选版本，主要涉及移动端体验、插件生态、实验性工作流和稳定性修复。

**主要变更**
- 完善手机和平板适配，优化软键盘、导航与窄屏布局；新增聊天文本引用、历史会话复制为 Markdown、统一右键与键盘菜单、文件预览目录树等交互能力。
- 插件管理支持富文本详情、第三方插件包更新；热更新失败时会尝试恢复旧版本。另新增日语、西班牙语、法语、德语、俄语和巴西葡萄牙语文案。
- 新增多项实验性能力：subagent_oar 工具可将独立任务交给本机 Codex 或 Claude CLI；新增个性化推荐、开发者工具统计插件；新增变更请求与 Git 工作树差异审阅流程。

**修复与优化**
- 改进会话发送确认、草稿保留、图片上传、侧栏与标签操作、运行状态展示，以及模型选择与排序等体验。
- 修复 AGENTS.md 预算分配、切换小上下文模型前压缩历史、Gemini 兼容接口工具调用签名、系统提示词缓存复用、图片数量超限、权限策略被意外改为完全访问、OpenCode 路由自动审核失败、后台任务等待与插话、技能目录读取失败等问题。
- 优化远程连接 WebSocket 压缩、Web 静态资源 ETag 缓存、会话状态更新和长回复流式组装开销，并改善 macOS Computer Use 权限引导。

**破坏性变更**
- 版本说明未提及破坏性变更，但该版本为候选版本，仍需按预发布版本对待。

**升级建议**
- 希望测试移动端、插件管理、工作树差异审阅和统计能力的用户可以试用；生产环境建议等待正式版，并重点验证插件热更新回滚、权限策略、长会话恢复和第三方模型兼容性。

## 2026-10-26 ~ 2026-11-01

- [dsh-v0.2.2-alpha.3](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-alpha.3) · 11-03

本周发布 dsh-v0.2.2-alpha.3（仍是 alpha 预发布）。重点是交互与审查体验：右键与键盘菜单在会话、工作区、侧边栏统一并支持开发者扩展；文件预览新增常驻目录树和当前文件定位；实验性的「变更请求与工作树」把本地与 PR 差异审查合并到统一入口，支持可搜索文件树、逐文件导航、把选中代码和评论交给 Agent，并跟踪检查与评审状态。体验上有手机端侧栏与窄屏布局改善、菜单浮窗保持在可视区并跟随缩放与软键盘、Trajectory 子调用可独立折叠、思考内容不再显示签名前缀，以及会话状态更新和流式回复组装的性能优化、底部输入框布局更稳定。修复包括：图片超出请求数量上限时自动省略最早图片以继续请求、OpenCode 路由下自动审核在工具执行前失败、alpha.2 引入的空会话被当作「未命名」并破坏排序、含旧版子代理描述的历史会话无法打开及搜索失败、压缩历史加载后聊天停止更新、Markdown 文件链接行号与行范围容忍、文件预览刷新后保留阅读位置、Trajectory 失败工具返回文本被合成错误覆盖、部分 run_code 记录缺少语法高亮。其他变更较多：同步 Cordis Core/Loader/Include 版本并统一配置与持久化行为；自动化任务改为宿主级统一管理；新增默认关闭的 apply_patch 多文件批量编辑工具；TypeScript/Python SDK 补齐命令与插件管理；macOS Computer Use 改用独立应用申请权限；pi-ai 支持动态请求头。需要注意的兼容与行为变化：原「Git 工作树」入口并入新功能，曾启用独立插件的用户需手动从 profile 的 dsh.profile.bundles 中移除该插件；文件修改的先读与外部修改防护改为默认关闭，沙箱与 Review 不变，需要旧防护的 profile 可显式恢复；并回退了 alpha.2 引入的跨行 $$ 数学块解析。说明未标注正式破坏性变更，但上述迁移与默认行为调整需评估。对使用 alpha 的团队值得升级，主要收益是修复 alpha.2 的会话与排序回归，以及审查和菜单交互改进；生产环境仍建议谨慎。
